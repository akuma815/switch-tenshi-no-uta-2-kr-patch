# 천사의 시 1·2 Switch판 Git 보완·재현·삭제 검토 인계

## 완료와 판정

사용자는 Switch판 천사의 시 1·2의 누락 파일을 공개 가능한 범위에서 Git에 보완하고 삭제 가능한지 검증하도록 요청했다. 원본은 `H:/ryujinx/Roms`, 업데이트는 `H:/ryujinx/Update`를 지정했다. **이번에는 검토와 보존까지만 완료했으며 두 게임 폴더는 삭제하지 않았다.** PC엔진판 `Games/Tenshi no Uta II - Datenshi no Sentaku (Japan)`는 범위 밖이다.

**조건을 유지하면 두 Switch 작업 폴더 모두 삭제 가능하다.** 지원 본편·업데이트·개인 키셋, 외부 도구, 두 Git 저장소 및 고정 릴리즈, 아래 비공개 편집 기록 백업을 유지해야 한다. Git 단독으로 원본이나 편집 프로젝트 전체가 복원된다는 뜻은 아니다.

| 대상 | 원격 재빌드 검증 | 삭제 전 게임 폴더 집계 |
| --- | --- | --- |
| `Games/Tenshi no Uta` | IoStore 53/53 자산 일치, 폰트 팩 동일 | 370파일, 455,837,112바이트 |
| `Games/Tenshi no Uta 2` | IoStore 76/76 자산 및 UFS 11/11 파일 일치, 폰트 팩 동일 | 995파일, 3,110,503,382바이트 |

집계는 이번 인계 문서를 갱신하기 전 기준이다. 두 트리의 재분석 지점은 0개였다. 삭제를 실행할 때는 정확한 대상 경로와 재분석 지점을 다시 검사한다.

## Git에 보완한 내용

- Galmuri11-Condensed·Galmuri9·Noto Sans CJK KR 글꼴과 기존 OFL 연결.
- 원본 Texture2D에서 최종 매뉴얼을 복원하는 VCDIFF 40개/32개. 각각 26,428,216/26,010,074바이트이며 원본·차분·복원 결과 해시를 모두 확인한다.
- 기존 최종본의 대사·비주얼신·UI·선택 화면 교체 계획 4종씩. 최신 XLSX/CSV 원장은 수정하지 않았다.
- 2편 카드 글꼴 아틀라스·추가 카드 편집 스크립트/번역표·독립적인 폰트 메트릭 스크립트. 1편 폴더에 대한 빌드 의존성을 제거했다.
- 지원 NSP·업데이트/Paks/배포 자산 해시, 빌드 입력 매니페스트, 외부 도구 해시, 고정 Python 의존성.
- 원본 추출·입력 복원·격리 빌드·배포 자산별 해시 검사 스크립트. 에뮬레이터 설치 경로 자동 덮어쓰기를 제거했다. 2편의 임시 CSV도 `work/csv/`에 생성하여 기존 번역 CSV를 변경하지 않는다.

현재 원장의 일부 대사·크레딧은 배포 당시와 달랐다. 2편의 기본 매뉴얼 비활성 설정도 v1.5와 달랐다. 최신 원장과 동결한 릴리즈 프로필을 분리해 보존하고, 기본 재현 빌드는 릴리즈 프로필 및 매뉴얼 32장을 사용한다. 번역을 새로 고치거나 배포 버전을 변경하지 않았다.

## 원격에서 수행한 검증

1. 공개 GitHub에서 새로 복제했다. 입력 확인 커밋은 1편 `9508fe7`, 2편 `1ddbf6b`이며 전체 SHA는 개별 원장에 있다. 최초 복원 진입점의 인자 누락은 수정하고 원격에서 fast-forward하여 다시 실행했다.
2. `extract_switch_paks.py`로 H:의 본편과 v1.0.1 업데이트를 새 비공개 디렉터리에 추출했다. 본편/업데이트 적용 후의 Paks 5개는 두 편 모두 동일했다. 기존 게임 폴더의 파일을 검증 체크아웃에 복사하지 않았다.
3. `build_reproducible.ps1`로 입력 복원·빌드·자산 해시 대조를 완료했다. 1편 입력 84개와 2편 입력 98개의 Git 매니페스트도 대조했다. Python 3.12.10의 기존 설치 환경을 사용했으며 새 OS/가상환경 설치 검증은 아니다.
4. 공개 배포 ZIP/7z를 다시 내려받아 컨테이너 4개씩을 고정 배포 해시와 확인했다. 새 빌드의 모든 IoStore 자산과 2편 UFS 파일을 그 배포와 대조했다.
5. 컨테이너 전체 바이트는 조립 순서/메타데이터 차이로 일부 다르다. 원장에 파일별 전체 해시 동일 여부를 별도로 기록했다. **원래 배포와 바이트가 동일한 컨테이너를 재빌드했다는 주장은 하지 않는다.**

이번 증거는 원본 추출·빌드·배포/자산 비교다. 새 에뮬레이터 실행·장면 시각 QA·전체 완주·실기·오디오 검수는 수행하지 않았다. 설치된 Citron/Eden 패치와 세이브도 변경하지 않았다.

## 2편 영상과 편집 원본의 보존 조건

2편 영상 10개는 Git의 텍스트/이미지 입력과 NSP만으로 다시 인코딩하지 않는다. 자막 편집 원본과 인코딩 명령을 찾지 못했으므로, 공개 v1.5의 `Tenshi_no_Uta_II_KR_Patch_V1.5_Final.7z`에서 해시를 확인하여 복원한다. SHA-256은 `044276f82d07e3707b8c3b633ee6304efa4f3093604eef2fae6061d9c6cce6b3`이며 다운로드와 복원을 실제 검증했다. 이 고정 릴리즈 입력을 유지해야 한다.

매뉴얼 차분은 cooked Texture2D를 복원하며 원래 편집 PNG의 무손실 원본을 재생성하지 않는다. 따라서 편집 PNG·번역 영상·과거 글꼴 소스·번역 원장·스크립트·문서 등은 아래 비공개 ZIP에 따로 보존했다. 원본 NSP/Paks·ISO·키·추출 캐시·실행 파일은 이 ZIP에 넣지 않았다.

| 백업 | 파일 수 | 압축 크기 | SHA-256 |
| --- | --- | --- | --- |
| `Tenshi_Switch_1_authoring_records_20261016.zip` | 81 + 매니페스트 | 166,836,330바이트 | `182cb25c44114a684e8b5ffa6be1fc44b265f5bf2c0ad9ca5fe42bf0addf627b` |
| `Tenshi_Switch_2_authoring_records_20261016.zip` | 100 + 매니페스트 | 285,590,108바이트 | `f35e0b0ceb56e918e651e65636947dcfbb8e846fbb7aa6af119477661e66d19b` |

두 ZIP은 이 인계와 같은 `work/tenshi_switch_rebuild_audit_20261016/`에 있다. ZIP CRC 및 선택 원본 파일마다 크기·SHA-256을 대조했다. 전체 게임 폴더 백업은 아니다. 세부 목록은 ZIP 내부 `ARCHIVE_MANIFEST.json` 및 `archive_verification1.json`, `archive_verification2.json`이다.

