2. `extract_switch_paks.py`로 H:의 본편과 v1.0.1 업데이트를 새 비공개 디렉터리에 추출했다. 본편/업데이트 적용 후의 Paks 5개는 두 편 모두 동일했다. 기존 게임 폴더의 파일을 검증 체크아웃에 복사하지 않았다.
3. `build_reproducible.ps1`로 입력 복원·빌드·자산 해시 대조를 완료했다. 1편 입력 84개와 2편 입력 98개의 Git 매니페스트도 대조했다. Python 3.12.10의 기존 설치 환경을 사용했으며 새 OS/가상환경 설치 검증은 아니다.
4. 공개 배포 ZIP/7z를 다시 내려받아 컨테이너 4개씩을 고정 배포 해시와 확인했다. 새 빌드의 모든 IoStore 자산과 2편 UFS 파일을 그 배포와 대조했다.
5. 컨테이너 전체 바이트는 조립 순서/메타데이터 차이로 일부 다르다. 원장에 파일별 전체 해시 동일 여부를 별도로 기록했다. **원래 배포와 바이트가 동일한 컨테이너를 재빌드했다는 주장은 하지 않는다.**

이번 증거는 원본 추출·빌드·배포/자산 비교다. 새 에뮬레이터 실행·장면 시각 QA·전체 완주·실기·오디오 검수는 수행하지 않았다. 설치된 Citron/Eden 패치와 세이브도 변경하지 않았다.
